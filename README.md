# بطل المهمات — ألعاب تعليمية 🦸

مجموعة ألعاب ويب تعليمية ثلاثية الأبعاد للأطفال (٤–٧ سنوات) بالعربي.
شخصية بنت صغيرة تنفّذ المهمات، وكل لعبة مرحلة مستقلة تُختار من القائمة.

## الألعاب الحالية

- **🏝️ جزيرة الحروف (المرحلة ١):** الحروف معلّقة عالأشجار زي الفواكه —
  اضغط الحرف الصح فتمشي البنت وتحمله، ثم اضغط الشكل الصح بلونه فتحطه.
- **🦁 حيوانات الحروف (المرحلة ٢):** ٣ حيوانات جعانة، وكل حيوان
  بيبلش اسمه بحرف معين (أسد = أ، بطة = ب…) — طعّم كل حيوان حرفه
  فيضغض ويقفر فرحان ويطلع قلب. لما تُطعَم الثلاثة تجي جولة جديدة
  بحيوانات جداد. كل الحروف العربية الـ٢٨ مدعومة، ولوحة الاسم فوق
  كل حيوان توضح الحرف الأول ملوّن.

- **🍲 مطبخ الوصفات (المرحلة ٣):** طاولة وقِدر طبخ وفواكه ملونة منثورة
  عالأرض — الطباخة بتقول "أحضر لي فاكرتين حمراوين!" والطفل يضغط
  الفواكه الصح (لون + عدد) فتجيبها البنت وتحطهن بالقِدر وحدة وحدة.
  لما تكتمل الوصفة يغلي القِدر وتطلع الأكلة بالاحتفال، وبعدها وصفة
  جديدة. بيتعلم العدّ (١–٣) والألوان معاً.

  الحيوانات الـ٢٨: أ أسد 🦁، ب بطة 🦆، ت تمساح 🐊، ث ثعلب 🦊،
  ج جمل 🐫، ح حوت 🐋، خ خروف 🐑، د ديك 🐓، ذ ذئب 🐺، ر راكون 🦝،
  ز زرافة 🦒، س سلحفاة 🐢، ش شمبانزي 🐒، ص صقر 🦅، ض ضفدع 🐸،
  ط طاووس 🦚، ظ ظربان 🐿️، ع عصفور 🐦، غ غزال 🦌، ف فيل 🐘،
  ق قطة 🐱، ك كنغر 🦘، ل لاما 🦙، م ماعز 🐐، ن نمر 🐆، ه هدهد (مرسوم)،
  و وحيد القرن 🦏، ي يعسوب (مرسوم) — معظمها إيموجي ناصع على لوحات
  (قابلة للاستبدال بصور AI أو موديلات 3D بنفس المكان)، والهدهد
  واليعسوب مرسومان يدوياً على الكانفس. لوحة اسم كل حيوان تعرض
  الحرف الأول بصيغته المتصلة أول الكلمة (هـدهد، بـطة، سلـحفاة).

## إضافة لعبة جديدة

أنشئ ملف `level3.js` يصدّر `start()` ويستدعي `registerGame(...)`،
وأضف `import('./level3.js')` بنهاية core.js — بتظهر بالقائمة تلقائياً.

## التشغيل السريع

افتح `index.html` بمتصفح كروم (عالتلفون هو الهدف)، أو شغّل:

```
node dev-server.mjs   ثم افتح http://127.0.0.1:8931/
```

- بدون ملفات صوت: اللعبة تنطق المهمات آلياً (TTS).
- مع ملفات صوت: حط التسجيلات بمجلد `audio/` بالأسماء تحت — بتشتغل فوراً بدون أي تعديل كود.

## التحكم

- **نقرة** على فاكهة الحرف / شكل الأرض / الحيوان = تنفيذ.
- **سحب** أفقي = تدوير الكاميرا حوالين البنت.
- زر 🏆🏠 يرجعك لقائمة الألعاب، وزر 🔊 يعيد سماع المهمة.

## بنية الملفات

```
index.html      صفحة اللعبة
style.css       الشكل
core.js         النواة المشتركة: المشهد، الجزيرة، البنت، الفواكه، الصوت، القائمة
level1.js       المرحلة ١ — جزيرة الحروف
level2.js       المرحلة ٢ — حيوانات الحروف
vendor/         مكتبة Three.js (محلية للعمل أوفلاين)
dev-server.mjs  سيرفر محلي للتجربة
audio/          ملفات التسجيل (mp3/m4a/wav)
2d-version/     النسخة المسطحة الاحتياطية
```

## قائمة التسجيلات المطلوبة

### مشتركة (المرحلتين)

| اسم الملف | النص |
|---|---|
| `hint_first` | أولاً أحضر الحرف! |
| `hint_carry` | ممتاز! الآن ضعه في مكانه الصحيح. |
| `praise_1` | أحسنت! |
| `praise_2` | رائع جداً! |
| `praise_3` | برافو عليك! |
| `retry_1` | حاول مرة ثانية، أنت تقدر! |
| `retry_2` | ليس هذا! انظر جيداً! |
| `done` | أكملت كل المهمات! أنت بطل حقيقي! |

### المرحلة ١ (جزيرة الحروف)

| اسم الملف | النص |
|---|---|
| `mission_1` | أحضر حرف الألف، وضعه في المربع الأحمر! |
| `mission_2` | أحضر حرف الباء، وضعه في الدائرة الزرقاء! |
| `mission_3` | أحضر حرف التاء، وضعه في المثلث الأصفر! |
| `mission_4` | أحضر حرف الثاء، وضعه في النجمة الخضراء! |
| `mission_5` | أحضر حرف الجيم، وضعه في المربع الأزرق! |
| `mission_6` | أحضر حرف الدال، وضعه في الدائرة الحمراء! |

### المرحلة ٢ (حيوانات الحروف)

| اسم الملف | النص |
|---|---|
| `intro_animals` | أهلاً! كل حيوان هنا بيبلش اسمو بحرف معين. اضغط على الحرف، وبعدين اضغط على الحيوان حتى تطعمه ياه! |

اختياري (٢٨ ملف) — أسماء الحروف اللي بتُنطق لما البنت تاخد الحرف
(بدونهن اللعبة بينطقها آلياً):
`letter_أ` = "الألف"، `letter_ب` = "الباء"، … `letter_ي` = "الياء".

### المرحلة ٣ (مطبخ الوصفات)

| اسم الملف | النص |
|---|---|
| `intro_kitchen` | أهلاً بالمطبخ! اسمع الوصفة واضغط على الفواكه الصح حتى نطبخ مع بعض! |

نصوص الوصفات بتتولد عشوائياً (لون + عدد) فبتنطق آلياً — إذا حاب
تسجلها بصوتك لاحقاً بنحط لها نظام مقاطع صوتية مقسمة.

### نصائح التسجيل

- غرفة هادئة، والتلفون على بعد ~٢٠ سم من الفم.
- كل جملة بملف لحالها، وبثانية صمت قبل وبعد الجملة.
- الاسم بالضبط متل الجدول، الصيغة mp3 أو m4a أو wav.

## الشخصية

الشخصية الحالية بنت صغيرة مبنية بالكود (Three.js primitives).
الألوان قابلة للتعديل من ثابت `GIRL` بـ core.js (`skin` البشرة،
`hair` الشعر، `dress` الفستان). لما توصل صورة المستخدم بتُفصّل
الشخصية لتشبه صاحبة الصورة.
